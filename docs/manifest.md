# Manifest reference

[Documentation](README.md) · Related: [Plugins](plugins.md), [Configuration](configuration.md)

A project starts with `digit.toml`. Use actual TOML: quote version strings and use tables for services.

## Complete network example

```toml
schema = 1
name = "friends"

[network]
bind = "127.0.0.1"
port = 25565
motd = "Friends' Minecraft network"

[services.proxy]
type = "velocity"
version = "latest"
fallback = ["lobby"]

[services.lobby]
type = "paper"
version = "1.21.11"
plugins = ["viaversion"]

[services.survival]
type = "paper"
version = "1.21.11"
memory = "2G"
plugins = ["viaversion"]

[services.survival.properties]
difficulty = "hard"
max-players = 20

[services.survival.env]
OPS = "YourMinecraftName"

[plugins.viaversion]
source = "modrinth"
project = "viaversion"
version = "latest"
```

For a standalone server, omit the proxy and leave exactly one Paper service. For a network, declare one Velocity service and one or more Paper services. Multiple Paper services without a proxy are rejected. At least one Paper service is required, including when a database is present.

## Project and network

| Field          | Meaning                                            | Default       |
| -------------- | -------------------------------------------------- | ------------- |
| `schema`       | Manifest format version                            | `1`           |
| `name`         | Project name                                       | Required      |
| `network.bind` | IPv4 or IPv6 address to listen on                  | `"127.0.0.1"` |
| `network.port` | Player connection port; `0` lets Docker assign one | `25565`       |
| `network.motd` | Server-list message                                | Project name  |

The ingress is the standalone Paper server or the network's Velocity proxy. Only that service publishes the player port. Paper backends and databases remain private to the Docker network.

Use `bind = "0.0.0.0"` to listen on all IPv4 host interfaces. This does not configure router forwarding or host firewalls. Named environments other than `dev` override the default binding and port unless a profile says otherwise; see [environments](environments.md).

## Minecraft services

| Field        | Meaning                                                   | Default                           |
| ------------ | --------------------------------------------------------- | --------------------------------- |
| `type`       | `"paper"` or `"velocity"`                                 | Required                          |
| `version`    | Minecraft version for Paper; Velocity version for proxies | `"latest"`                        |
| `build`      | Exact build number as a string, or `"latest"`             | `"latest"`                        |
| `channel`    | `"stable"` or `"experimental"`                            | `"stable"`                        |
| `memory`     | Positive whole amount ending in `M` or `G`                | Paper: `"2G"`; Velocity: `"512M"` |
| `plugins`    | Declared plugin aliases to install                        | `[]`                              |
| `fallback`   | Ordered Paper destinations, Velocity only                 | Inferred only with one backend    |
| `properties` | Scalar server properties, Paper only                      | Empty                             |
| `env`        | Additional supported image options                        | Empty                             |

With more than one backend, set the proxy's fallback explicitly, for example `fallback = ["lobby"]`. Names in that list must name Paper services. Service names also become Velocity backend names and internal hostnames.

Paper 1.19 and newer are supported by this candidate. Selecting `channel = "experimental"` permits prerelease builds. The initializer reads the current PaperMC catalog and sets that channel when you choose an experimental version.

`latest` is resolved into `digit.lock`; existing deployments do not silently upgrade on each start. See [dependency updates](plugins.md#update-locked-dependencies).

## Database services

```toml
[services.database]
type = "mariadb"
version = "11.8"
```

`version` defaults to `"11.8"`. Databases can use additional non-managed `env` options, but not Minecraft `build`, `channel`, `memory`, `plugins`, `fallback`, or Paper properties. Credentials and the application database are generated by digit. See [database references](configuration.md#databases).

## Names and validation

Project, service, plugin-alias, environment, and profile names use 1–40 lowercase letters, digits, hyphens, or underscores, starting with a letter. Object-reserved names such as `constructor` are rejected. Service names `project`, `environment`, and `service` are reserved for configuration references. A Paper backend in a Velocity network cannot be named `try`.

Modrinth project IDs are separate from aliases and may contain uppercase letters. The initializer creates a valid alias while preserving the original ID.

Unknown fields fail with their location. digit reserves software selection, authentication, forwarding, ports, RCON, image download/copy controls, and related wiring. For example, choose memory with `memory`, not `env.MEMORY`, and declare plugins under `[plugins]`, not `env.PLUGINS`. `JVM_OPTS` and `JVM_XX_OPTS` remain available for deliberate JVM customization.
